# Сайт-визитка барбера Tamer Örcü

Одна страница на русском. Записи на сайте нет: клиент выбирает место и удобное время,
сайт собирает сообщение и открывает мессенджер. Сайт ничего не хранит и никуда не отправляет.

Предпросмотр: https://loakfh.github.io/barber-site/ (закрыт от поисковиков).
Пять вариантов дизайна первого этапа: https://loakfh.github.io/barber-site/preview/

Стек: Astro собирает статическую страницу, интерактив на обычном JavaScript,
шрифты и картинки лежат локально. Снаружи подгружаются только Яндекс Карты, и только
когда до карты долистали.

## Запуск

```sh
npm install
npm run dev      # правки видны сразу
npm run build    # сборка в dist/
npm run serve    # посмотреть собранный сайт: http://localhost:4330
```

Нужен Node.js 22 или новее.

## Где что менять

Всё лежит в `content/site.config.json`. Вёрстку трогать не нужно.

| Что | Поле |
|---|---|
| Телефон, Telegram, WhatsApp, MAX, Instagram | `contacts`. Пока `maxUrl` пустой, кнопки MAX нет |
| Локации | `locations`, формат ниже |
| Услуги | `services`: `id`, `title`, `line` |
| Цифры первого экрана | `stats` |
| Строка под именем и строка на развороте | `hero.tagline`, `cover.line` |
| Фраза манифеста и перевод | `manifest.line`, `manifest.translation` |
| Блок «О мастере» | `about`: `big` (крупно), `small` (мелко) |
| Отзывы | `reviews`: `name`, `source`, `text`. Пустой список: секции нет |
| Галерея | `gallery`: `id` фото, `type`, `alt`; типы в `galleryTypes` |
| Пометки «черновик» | `"draft": true` у строки; убрать все разом: `site.showDraftMarks: false` |
| Адрес сайта | `site.url` |

Цен и длительности на сайте сейчас нет. Когда появится прайс, добавьте услугам поля
`price` и `duration` и скажите разработчику: вывод этих полей в вёрстке пока не сделан.

### Локация

```json
{
  "id": "taganka",
  "name": "Название коворкинга",
  "metro": "Таганская",
  "address": "ул. Примерная, 1",
  "coords": [55.74, 37.65],
  "hours": { "mon": ["10:00", "20:00"], "thu": ["12:00", "21:00"] },
  "howToGet": "Вход со двора, второй этаж",
  "entrancePhoto": ""
}
```

Это пример формата, а не настоящий адрес. В `hours` указываются только дни приёма
(`mon tue wed thu fri sat sun`), время московское. Добавить или убрать локацию: правка
этого списка. От него строятся секция «Где», карта, статус «сейчас принимает»,
кнопка «Маршрут», панель записи, строка метро на первом экране, title и JSON-LD.
Пока список пустой, секции «Где» и кнопки «Маршрут» нет, а панель записи предлагает
просто написать Тамеру.

Поле `entrancePhoto` зарезервировано: фото входа в карточке пока не выводится.

### Фото и видео

1. Положите исходники в `content/photos/raw/` и `content/video/raw/` (в репозиторий они не попадают).
2. Впишите имена файлов без расширения в `content/media-use.json`. На сайт и в репозиторий идут только файлы из этого списка.
3. `npm run media` сделает AVIF и WebP в нескольких ширинах, mp4 и webm без звука и постер.
4. Добавьте фото в `gallery` в конфиге.

Вырезанный портрет: `content/photos/hero-cutout.png`. Его правый край должен быть срезом кадра: на сайте портрет прижат к правой стенке.

Картинка для мессенджеров (`public/og.jpg`): `npm run build && npm run og && npm run build`.

## Панель записи

Весь компонент: `src/scripts/booking.js`. Источник доступного времени: одна функция
`getAvailability`. Сейчас она читает график из конфига; чтобы подключить настоящие
слоты, замените её тело и верните тот же формат.

## Как выложить на боевой хостинг

1. Впишите домен в `site.url`, например `https://example.ru`.
2. `npm run build`.
3. Залейте содержимое папки `dist/` в корень сайта:
   - reg.ru или Timeweb: файловый менеджер или SFTP, папка `public_html`;
   - Yandex Cloud Object Storage: бакет с именем домена, включить «Хостинг», главная страница `index.html`, залить `dist/` через консоль или `aws s3 sync dist/ s3://имя-бакета --endpoint-url=https://storage.yandexcloud.net`.
4. Проверьте `https://домен/robots.txt` и `https://домен/sitemap.xml`.

Боевая сборка открыта для поисковиков. Предпросмотр на GitHub Pages собирается с
переменной `SITE_BASE=/barber-site/` и получает `noindex`: это делает
`.github/workflows/deploy.yml` при каждом `git push` в `master`.

Яндекс Метрика не подключена: номера счётчика нет. Когда появится, понадобятся плашка
про cookie и страница политики.
